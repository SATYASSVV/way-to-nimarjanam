# Vocals-only Ganapathi Audio

You can place an original or properly licensed vocals-only devotional recording in this directory with the filename:
`ganapathi-vocals.mp3` (i.e. `public/audio/ganapathi-vocals.mp3`).

When present, the game detects and plays the vocal track after clicking "START HERE" or toggling sound ON.

No recording is included in this repository. When no file is present, the game uses browser speech synthesis for occasional "Ganapathi Bappa Morya!" and "Jai Ganesh!" vocal chants. It does not start instrumental music, drums, or a generic soundtrack.
